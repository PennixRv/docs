记忆搜索和上下文读取现在会以有界分阶段处理 Codex JSONL rollout。跨读取边界的 UTF-8 字节会安全解码，compaction 恢复会保留重复输入，搜索输出限制 excerpt 数量，上下文输出会把截断标记计入字符预算。这些改动减少查询过程保留的完整对话正文，但不宣称所有调用方或文件格式都具有恒定内存上界。

工作流指南现在区分 Trellis 托管资产和项目自有文件，按选定工作流而不是单独按平台能力决定派发路径，并要求归档任务前执行验收核对。批量会话历史研究会在提取对话前记录资源限制、授权范围和输出边界。

默认 inline Codex 工作流明确记录派发和写入边界。Marketplace 工作流资产同步采用这些规则，CLI 和 core 继续保持同一发布版本。
