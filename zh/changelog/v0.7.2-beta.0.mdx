本版保持 npm `beta` 通道，版本高于现有 stable `0.7.1`。

- 保留每次尝试的 report/worklog，返回全尝试索引，保存有界 provider 诊断；证据清理需要先预览，再确认对应摘要。
- 按实际成员数和其他批次的持久预留计算容量；读取终态结果不重新占用容量。冻结语义默认值，拒绝扩大的运行时覆盖，派发前重新核对参考资料。
- 新增原批次核销与失败子集重试计划；退出证明不足时保留 lease，重试关联原计划且不重跑成功项。
- 新增 Codex 等待投影及宿主支持范围内的工具 Hook 护栏，要求静默续接原句柄；不承诺阻止模型唤醒或普通发言。
- 委派前绑定子 PRD、角色、Git base、分支与结果路径；保留执行历史，提供安全核销和显式 ownership 恢复，修正解绑和启动的失败副作用。
- 修正取消与实施回退、Pi/OMP、坏阶段诊断、初始化顺序、Copilot 重复模板、单文件备份和发布重试。
- 退休隐式 Marketplace Spec 来源；init 提供索引/guides，bootstrap 按源码生成适用规范并保留自定义内容。显式 registry 继续受支持。

安装本版后通过原生 `trellis update` 更新项目资产，明确处理自定义文件冲突。本轮没有重测 Claude、DSH 真实账号，相关协议行为以 fixture 验证为限。
