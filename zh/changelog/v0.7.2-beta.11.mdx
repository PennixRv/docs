title: 'v0.7.2-beta.11'
description: '采用通用 spec 入口，并在原生生命周期操作中保护共享 AGENTS 内容。'
---

新项目从通用 spec 索引开始，不再推断并生成 frontend/backend 目录；具体主题根据真实代码证据补充。已有目录及任务 package 绑定继续受支持，重初始化不重命名或删除已有规范。消费端发现根索引并遵守 package 作用域。

项目 AGENTS 默认模板说明入口职责，导航到 workflow、spec、Skills 和协作机制。普通初始化在验证已有文件后安全追加缺失的 TRELLIS 块；已有合法块默认保留，明确选择替换时才更新。`--skip-existing` 保留显式跳过语义。强制替换只修改 TRELLIS 块，其他生成资产仍遵循各自的覆盖合同。

更新、卸载、受管移除和资产恢复共用更严格的区间及路径检查，保留手工正文、其他 owner 的块和归属区间外的空白。异常标记和不安全路径拒绝写入；后来新增的他方内容使删除文件或恢复旧全文不再安全时，原生恢复保留冲突。既有摘要仍可能产生保守冲突，本次不提供全局事务或对任意外部 writer 的互斥保证。

升级 CLI 后，通过原生 `trellis update` 更新已管理项目。新项目初始化仍须明确目标及授权。共享 Pennix Skills 通过自身 owner 发布和部署跨组件编排方法；项目接入不隐含索引创建授权。
