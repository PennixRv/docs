所有支持平台的原生用户 workflow、默认任务 PRD、workspace 总索引、个人日志与索引，以及 spec 源模板现采用简体中文正文和中文优先双语标题。机器标识、命令、代码示例、托管 AGENTS 指令、平台 AI 专属资产和第三方 workflow 保留现行合同。跨平台思考指南仍是默认生成指南集合之外的源模板。

阶段提取、SessionStart 消费者和 workflow 保存校验接受完整的旧英文标题及新双语标题。新日志记录使用中文优先标签，保留旧记录，并维持编号、重试、去重、历史合并和轮转行为。

本版本不添加文档翻译迁移。已有任务 PRD、日志、workspace 文件和 spec 仍受保护。原生 workflow 更新继续按哈希替换，并保留 skip、overwrite 和旁路文件等冲突选择；第三方 workflow 的所有权不变。
