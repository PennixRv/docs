Pennix v0.7 beta 任务生命周期可发现性维护版本。

## 修复

### 任务帮助中显示 replan 命令

`task.py replan` 原本已经能够将执行中的任务返回规划阶段并记录可审计原因。
现在标准任务帮助也会列出该命令，使受支持的规划恢复路径可以直接从 CLI 中发现。

## 升级

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

无需 `--migrate`。
