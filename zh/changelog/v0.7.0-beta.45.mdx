beta.44 发布时先发布了包元数据，未包含同步的 Core 记忆改动。本 beta 以新版本重新发布完整的有界 Codex 记忆查询实现和发布暂存修复。

Codex JSONL 查询现在会安全处理跨读取边界的 UTF-8 序列，保留 compaction 恢复和重复输入，限制搜索过程保留的 excerpt，并把截断标记计入上下文字符预算。这些改动减少查询过程保留的完整对话正文，但不宣称所有调用方或文件格式都具有恒定内存上界。

工作流指南继续区分 Trellis 托管资产和项目自有文件，按选定工作流决定派发路径，要求归档前执行验收，并在批量会话历史提取前记录资源限制。
