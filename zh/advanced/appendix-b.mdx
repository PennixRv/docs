## 附录 B：命令与 Skill 速查

Trellis 提供平台相关的会话命令、内置 Skill 和任务 CLI。各宿主平台支持的原生命令或 agent 能力有所不同。

### Slash 命令（按平台）

常规用户命令是 `finish-work` 和 `continue`。`start` 只在不会自动注入会话上下文的平台上作为用户入口出现。调用语法按平台不同：

| 平台                                                    | Start                                                                     | Finish                 | Continue            | 交付形式                                |
| ------------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------- | ------------------- | --------------------------------------- |
| Claude Code / OpenCode / Gemini CLI / CodeBuddy / Droid | SessionStart hook 自动注入                                                | `/trellis:finish-work` | `/trellis:continue` | Slash 命令                              |
| Cursor / Pi Agent / Qoder                               | SessionStart hook 或 extension 自动注入                                   | `/trellis-finish-work` | `/trellis-continue` | 原生命令 / prompt                       |
| Kiro                                                    | `@trellis:start`                                                          | `@trellis:finish-work` | `@trellis:continue` | Skill，通过 `@` 选择器                  |
| Kilo                                                    | `/start.md`                                                               | `/finish-work.md`      | `/continue.md`      | Workflow 文件（`.kilocode/workflows/`） |
| Antigravity / Devin                                     | workflow 选择器 → `start` / `finish-work` / `continue`                    |                        |                     | Workflow 文件                           |
| GitHub Copilot                                          | Run Prompt → `trellis-start` / `trellis-finish-work` / `trellis-continue` |                        |                     | Prompt 文件（`.github/prompts/`）       |
| Codex                                                   | 自动读取 `AGENTS.md` prelude；可选 UserPromptSubmit hook                  | skill / prompt 入口    | skill / prompt 入口 | Skills + hooks                          |

### 内置 Skill

五个阶段 Skill 分别提供对应阶段的详细流程；其他内置 Skill 用于项目定制、会话历史、规范工作和协作。

| Skill                                             | 用途                                  |
| ------------------------------------------------- | ------------------------------------- |
| `trellis-goal-exploration-and-requirements`       | 建立并确认任务需求。                  |
| `trellis-decision-space-construction-and-merging` | 识别并收敛实质决策。                  |
| `trellis-solution-design-and-convergence`         | 形成并收敛实施合同。                  |
| `trellis-task-implementation`                     | 实施并验证已获授权的工作。            |
| `trellis-delivery-review-and-closeout`            | 审查交付并确定任务收尾结果。          |
| `trellis-meta`                                    | 检查和定制项目中的 Trellis 资产。     |
| `trellis-session-insight`                         | 通过 `trellis mem` 回溯相关历史会话。 |
| `trellis-spec-bootstrap`                          | 创建或更新项目规范。                  |
| `trellis-teamwork`                                | 通过 Trellis Teamwork 协调协作。      |

### 原生 agent

Trellis 可接入各宿主提供的 agent 能力。工作流可以在主会话中运行，也可以在宿主和任务适用时委派；不要求固定的 agent 名称。详见[多平台支持](./multi-platform)和[Teamwork](./teamwork)。

### 全局 CLI 命令

| 命令              | 用途                                  | 用法                                           |
| ----------------- | ------------------------------------- | ---------------------------------------------- |
| `trellis upgrade` | 升级全局安装的 Trellis CLI package    | `trellis upgrade [--tag <tag>]`                |
| `trellis update`  | 把当前项目的 Trellis 文件同步到此 CLI | `trellis update [--dry-run] [--migrate] [...]` |

### `task.py` 子命令

| 子命令        | 用途                                       | 用法                                                              |
| ------------- | ------------------------------------------ | ----------------------------------------------------------------- |
| `create`      | 创建任务，标题和非空描述为必填项。         | `task.py create "标题" --description "描述"`                      |
| `start`       | 将任务设为当前会话的活动任务。             | `task.py start <任务目录>`                                        |
| `phase`       | 查看或更新任务阶段路线和阶段记录。         | `task.py phase show <任务目录>`                                   |
| `workflow`    | 选择或清除任务专用 workflow 变体。         | `task.py workflow --help`                                         |
| `add-context` | 添加任务上下文条目。                       | `task.py add-context <任务目录> <文件> <路径> <原因>`             |
| `validate`    | 校验任务上下文文件。                       | `task.py validate <任务目录>`                                     |
| `list`        | 列出任务。                                 | `task.py list`                                                    |
| `finish`      | 清除当前会话的活动任务指针，不会完成任务。 | `task.py finish`                                                  |
| `complete`    | 接受收尾结果后完成任务。                   | `task.py complete <任务目录>`                                     |
| `cancel`      | 记录取消原因并引用任务内的证据文件。       | `task.py cancel <任务目录> --reason <原因> --evidence-ref <文件>` |

`complete` 和 `cancel` 更新任务生命周期；`finish` 只结束当前会话对该任务的选择。已完成任务仍保留在 `.trellis/tasks/` 中。

### Python 脚本

```bash
# 上下文
./.trellis/scripts/get_context.py                 # 完整上下文
./.trellis/scripts/get_context.py --json          # JSON
./.trellis/scripts/get_context.py --mode packages # 按 package 的 spec 层（monorepo）
./.trellis/scripts/get_context.py --mode record   # 给 /trellis:finish-work 用

# 会话
./.trellis/scripts/add_session.py --title "..." --commit "..." --summary "..."

# Spec bootstrap（首次）
./.trellis/scripts/create_bootstrap.py
```
