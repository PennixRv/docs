## 主会话 Hook

Hook 负责主会话启动上下文、任务与阶段提示、按路径加载规范以及 shell 会话身份。任务状态由 Task CLI 写入，实施权限来自用户接受的合同。Hook 不创建原生子代理、不改写委派工具参数，也不把工具可用性解释为授权。

平台事件、信任和启用要求不同，核对当前生成的注册文件和宿主真实回执。Claude Code 使用 `.claude/settings.json`；Codex 使用 `.codex/hooks.json`，其启用与信任由宿主管理；OpenCode 使用 `.opencode/plugins/`；Pi 和 Oh My Pi 使用各自 extension；Snow 使用主会话 session/user Hook。没有自动 Hook 的平台通过项目入口和 Skills 加载上下文。

## 上下文与身份

主会话读取 `prd.md`、`design.md`、当前阶段和相关 spec。`implement.jsonl`、`check.jsonl` 是按需创建的可选上下文清单，不是执行路由。OpenCode 的 `inject-shell-session-context.js` 只传递受管 shell 身份，保留显式身份覆盖；它不物化角色或启动其他会话。

修改 Hook 前读取 `trellis-meta` 中对应平台说明和现有注册。保留错误处理、会话隔离、锁及上下文预算；不要复制凭据或运行态。用宿主真实输入验证主会话事件、无任务场景、已有任务和显式身份覆盖。

## 更新与恢复

`trellis update` 按归属与指纹删除旧子代理 Hook 和精确注册，保留同一文件中的无关用户配置。修改过的旧执行资产、跳过规则及不安全路径会阻断更新。原生恢复入口拒绝重新激活退休的角色、执行器和 Hook；历史记录不作为可执行配置。
