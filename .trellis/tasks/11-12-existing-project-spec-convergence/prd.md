# 既有项目 spec 入口与治理说明

本仓库作为独立 docs-site owner，承接根任务第 2 版合同 W4 和用户“直接完整推进，包括发布部署和重装”的完整授权。仅同步当前线六份中英文说明及发行 changelog，保留历史线与导航规则。

验收：中英文行为一致、真实重入行为明确、共享导航及所改文件格式检查通过；文档提交先推送，再由 Trellis 固定 gitlink 发布。
