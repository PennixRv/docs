Pennix v0.7 beta maintenance release for ownership-aware project updates.

## Fixes

### Keep project extensions out of `.new` conflicts

Trellis now composes generated configuration by ownership. Top-level project
sections in `.trellis/config.yaml` and undeclared settings or tables in
`.codex/config.toml` survive template refreshes without being hardcoded into
the Trellis templates.

`AGENTS.md` now auto-updates when only its valid `TRELLIS` managed block
changes, while prose outside that block remains untouched. Malformed or
duplicate markers continue to use the normal conflict path.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
