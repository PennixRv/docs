User modifications, unknown ownership, exclusions and unsafe paths block updates. Unrelated user configuration remains intact. Initialization, workflow activation and native restore reject retired execution assets.

Only the main session selects `trellis teamwork` or `paseo-based-parallelism` under the current contract. History, available tools and recovery summaries do not expand authorization.

The shared Reasonix check path replaces an owned retired role with the ordinary check Skill using preflight fingerprints. Unsafe replacement blocks before writes. Beta.13 was a cancelled, undeployed candidate; this version is the complete retirement candidate.
