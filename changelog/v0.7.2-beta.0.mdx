This beta moves above stable `0.7.1` while keeping the `beta` npm channel.

- Retain every attempt report/worklog, expose attempt indices, preserve bounded provider diagnostics, and require explicit preview confirmation for evidence cleanup.
- Count actual assignments and other batch reservations; read settled results without fresh admission. Freeze semantic defaults, reject expanded runtime overrides, and recheck references before dispatch.
- Add native original-batch reconciliation using process exit/birth evidence and linked retry plans containing only explicitly approved failed work.
- Add a Codex wait projection and supported-tool Hook guard; silently continue the original host handle. Host wake-ups and ordinary model messages remain outside this guard.
- Bind delegated PRD, role, Git base, branch and output path before resource creation. Preserve execution history, provide safe reconciliation and explicit ownership recovery, and prevent unsafe unlink/start side effects.
- Correct cancellation/rework routes, Pi/OMP integration, malformed phase diagnostics, initialization order, duplicate Copilot templates, single-file backups and publication retries.
- Retire the implicit Marketplace spec source. Init provides indexes/guides; bootstrap derives applicable conventions from source and preserves custom specs. Explicit registries remain supported.

Update project assets with the native `trellis update` command after installing
this beta. Review customized-file conflicts explicitly. Claude and DSH live
account behavior was not revalidated; protocol fixtures remain the coverage for
those providers.
