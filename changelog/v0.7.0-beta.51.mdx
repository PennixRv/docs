Planned change-bearing work now presents the final plan before sealing, then asks whether to seal and approve proceeding or supplement/revise. One explicit combined reply authorizes native seal, approval recording with the returned revision, and task start for that same plan. Feedback remains in planning, seal-only requests do not start implementation, and existing sufficient authorization is reused on resume.

The default workflow, planning and continuation entries, Copilot prompt, and bundled task references share this order. Task identity, version and content-digest gates remain unchanged; material plan changes require renewed final review. Direct small work and analysis-only research retain their existing paths. This release adds no task schema or history migration.
