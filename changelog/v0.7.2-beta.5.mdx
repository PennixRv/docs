title: 'v0.7.2-beta.5'
description: 'Authorized result packages in independent same-host Paseo worktrees.'
---

This beta adds worktree delegation for complete authorized implementation packages. Trellis owns task authority, preparation and implementation permission, recovery and acceptance; Paseo owns native workspaces and agents. Teamwork continues to provide read-only evidence.

- Freeze the target checkout, owner branch, base commit, role, settings and capability requirements before preparation. Targets can be independent repositories or have no Trellis assets.
- Keep the stable delegated role separate from per-attempt context and per-turn actions. Nodes read native user/project instructions and never create a second controller workflow.
- Persist creation and send intents before native writes. Unknown outcomes require exact native resource mapping and explicit recovery, without replaying an unknown create or send.
- Review and merge/fast-forward the source result into its target owner branch before reconciliation. Idle and cancellation alone do not prove background writers stopped; resources remain preserved.

The optional `@pennixrv/trellis-paseo-adapter` uses public Paseo SDK packages and requires Node 22 or later. Core and CLI remain independent of that package and retain Node 18.17 support. Install the optional adapter through its registered lifecycle owner and use native `trellis update` to refresh scripts, roles, hooks and `trellis-worktree-delegation`. New delegation requires explicit target, settings and requirements; existing records must be preserved and reconciled before moving to the new protocol.
