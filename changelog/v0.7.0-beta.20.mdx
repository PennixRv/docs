Pennix v0.7 beta maintenance release for ownership-aware project updates.

## Fixes

### Preserve project extension comments during updates

When Trellis composes an undeclared top-level project section in
`.trellis/config.yaml`, it now keeps the project's adjacent comments and
original formatting boundary. A valid project extension therefore remains
byte-stable after an update instead of producing a false `.new` candidate.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
