Pennix v0.7 beta planning and evidence governance release.

## Features

### Keep complex analysis in planning

`analysis_only` now remains limited to a bounded evidence deliverable. Work that still needs a material decision, implementation plan, cross-owner coordination, security, deployment, release, credential action, or a downstream change follows normal complex planning and the Planning Seal before implementation.

### Persist recoverable evidence

Read-heavy research, audit, and review now use bounded evidence units that persist a conclusion or blocker before more exploration. Explicit Codex subnodes use schema version 2 reports with per-scope coverage, evidence-linked findings, typed notes, and worklog checkpoints; the coordinator remains the only acceptance authority.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
