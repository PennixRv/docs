---
title: 'Trellis 0.7.1'
description: '2026-11-02'
---

Trellis 0.7.1 establishes the Pennix fork's bundled native workflow as the default. The task record keeps business-phase progress separate from task lifecycle and session handoff. Five independently defined phase workflows can be selected for each task; requirement revisions invalidate acceptance tied to an earlier revision. Trellis CLI validates phase changes and task completion against the current record.

The former Channel feature is now Trellis Teamwork across its CLI, API, storage, templates, and documentation. Teamwork coordinates specialist assignments and reports while keeping the coordinator responsible for integration.

The release also adds controlled Paseo task delegation, improves task ownership recovery and memory access, and updates the bundled Skills and project templates for the current workflow.
