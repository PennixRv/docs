Pennix v0.7 beta maintenance release for synchronized task templates.

## Fixes

### Packaged and dogfood task scripts are identical

The beta release now includes the synchronized `.trellis/scripts/task.py` copy
and packaged template. New and updated projects therefore receive the same
discoverable task help, including the `replan` command.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
