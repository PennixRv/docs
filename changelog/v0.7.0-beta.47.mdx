Native user-facing workflow, default task PRD, workspace index, personal journal and index, and spec source templates now use Simplified Chinese prose with Chinese-first bilingual headings across supported platforms. Machine identifiers, commands, code examples, managed AGENTS instructions, platform-specific AI assets, and third-party workflows retain their existing contracts. The cross-platform thinking guide remains a source template outside the default generated guide set.

Phase extraction, SessionStart consumers, and workflow save validation accept complete legacy English headings and the new bilingual headings. New journal entries use Chinese-first labels while preserving legacy entries and maintaining numbering, retry, deduplication, history merging, and rotation behavior.

This release adds no document translation migration. Existing task PRDs, journals, workspace files, and specs remain protected. Native workflow updates retain hash-based replacement and the existing skip, overwrite, and sidecar conflict choices; third-party workflow ownership is preserved.
