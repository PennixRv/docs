The shared `trellis-session-insight` skill distinguishes current project facts,
raw local conversation recall, and user-maintained knowledge. It chooses the
source by intent, supports explicit promotion through the destination owner,
and introduces no mandatory preload or automatic synchronization.

Task, handoff, and `mem` runtime behavior are unchanged. Upgrade the paired
CLI/core release and run `trellis update` in existing projects to refresh the
bundled instructions while preserving their selected workflows and history.
