title: 'Trellis 0.7.1-beta.9'
description: '2026-11-03'

Request intake replaces the generated brainstorm entry across 22 platforms. Goal exploration, alternative discovery, complete solution review, and separate implementation authorization stay with the five business phases. Known generated legacy Skills are removed by content hash; customizations and task/handoff history remain protected. Supporting Trellis Skills and the coordinated Pennix and Extra collections now follow the same responsibilities.

The new [asset maintenance commands](/beta/guides/asset-maintenance) create private verified snapshots, preview conflict-aware restores, preserve recovery snapshots, and clean resolved backups with explicit retention or full cleanup. Asset writers share a project maintenance lock; async operations retain it until completion. Task runtime mismatch, unknown locks, incomplete objects, and active recovery fail closed.

`trellis mem` rejects unknown, duplicate, missing-value, and inapplicable flags rather than silently ignoring them. Search retains multiword queries; historical phase slicing remains supported.

Upgrade the CLI to `0.7.1-beta.9`, preview `trellis update --dry-run`, then update each project. See [Skill Responsibilities and Routing](/beta/guides/skill-routing). No `--migrate` is needed for the Skill replacement. Backup cleanup is a separate explicit operation; it is never automatically performed by updating.
