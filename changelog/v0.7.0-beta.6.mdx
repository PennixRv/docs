Pennix v0.7 beta release hardening.

## Bug Fixes

### Release pushes only its own tag

`release:beta` now pushes the release branch and the tag it just created. It no longer uses `git push --tags`, which could publish unrelated local tags and trigger unintended npm workflows.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
