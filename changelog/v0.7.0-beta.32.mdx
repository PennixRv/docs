Start and continue instructions reuse a known session or compaction checkpoint,
load only missing or conflicting context, and resume the pending action without
replaying consumed user input. Shared descriptions and the Codex bootstrap notice
now match that boundary. Native identity, ownership and protected writes retain
their existing checks.

Active planning callers use `pennix-decision-grill`. Upgrade the paired CLI/core
release and run `trellis update` to refresh generated assets. Refresh an explicitly
selected Marketplace workflow separately through `trellis workflow`; preserve
project configuration, tasks and history. These are agent guidance changes,
not a host waiting policy or a new recovery runtime.
