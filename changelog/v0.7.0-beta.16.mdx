Pennix v0.7 beta workflow maintenance release for Hindsight-backed coordinator memory.

## Fixes

### Subnodes no longer write or consume coordinator memory

The generated `subnode` role now sets `HINDSIGHT_DISABLED=1`. Evidence workers remain
focused on bounded research and return their findings to the coordinator, while the
coordinator retains ownership of explicit project-memory writes and session handoffs.

The bundled handoff documentation and marketplace contract now describe the Hindsight
boundary instead of the retired OpenViking boundary.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
