This beta strengthens the two planning phase methods without adding stages, approval gates, or fixed interview rounds.

- Challenge material defaults against current-task usage, failure, or delivery scenarios before decision-space handoff, and retain unknowns with their affected decisions and follow-up paths.
- Reconsider affected choices after user answers, evidence, solution revisions, and review findings; an empty list of ready questions alone does not establish completeness.
- Record key review findings and their disposition in existing artifacts before requesting overall approval. Where release and installation apply, distinguish locally verified artifacts, published artifacts, and running identities.
- Keep exploration bounded, reuse settled decisions and sufficient authorization, and stop normally when material unknowns have been handled.

Install this beta and run the native `trellis update` command to refresh project skills. Review customized-file conflicts explicitly. These instruction changes do not establish measured model-behavior improvements.
