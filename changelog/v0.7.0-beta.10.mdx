Pennix v0.7 beta workflow consumer parity release.

## Improvements

### Keep selected workflow consumers aligned

The Codex Subnode Channel Marketplace workflow now carries the same planning
and recovery contracts as the native Trellis workflow: answer persistence and
frontier recalculation, implementation-time `task.py replan`, unbound task
states, and direct Phase 3.4 commit semantics without a duplicate confirmation
state. Marketplace consumers can now receive these rules from the published
workflow instead of maintaining local behavior forks.

## Upgrade

```bash
npm install -g @pennixrv/trellis@beta
trellis update
```

No `--migrate` required.
